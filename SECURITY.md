# Security policy

The supported security and deployment boundaries for this fork are documented
in [docs/security.md](docs/security.md).

Do not send Alkaid fork vulnerabilities to the former upstream security mailbox
and do not publish sensitive details in a GitHub issue. Submit reports through
[GitHub private vulnerability reporting](https://github.com/alkaid/pitaya/security/advisories/new).
This is the fork-owned private reporting channel; reports for this fork should
not be sent to the upstream project.
